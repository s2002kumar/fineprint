# DST-08 human review runbook and source links

**Purpose:** make the 52-item independent review fast, traceable, and tied to the exact DailyMed label versions. This file is a navigation aid, not a human sign-off. It does not prefill or replace `final_human_worksheet.csv`.

## Acceptance criteria

- **Random precision sample:** at least **29 of 30** `P-R9-*` items must be confirmed.
- **Version-aware acceptance:** all **8 of 8** `V-*` items must be confirmed.
- **Policy decisions:** 4 rows (`W-R1-07`, `W-R1-09`, and two `M-5_or_more...` rows).
- **DIRECT conflicts:** 10 establishment-level rows. These are not source-link additions; the decision is how to display/classify existing DIRECT label claims against registration evidence.

## Review method

For each random sample item:
1. Open the **exact citing version** using the version ZIP link; verify the cited source NDC occurs on the expected product's `asEquivalentEntity` element.
2. Open the **exact source version** using the version ZIP link; verify the cited source NDC identifies the expected product and that dosage form, active ingredient(s), and strength(s) match.
3. In the source XML, inspect the `manufacturedProduct` for that exact product code and its associated establishment `performance`; confirm the operation is `MANUFACTURE` and record the site DUNS.
4. Compare the stated physical characteristics when applicable. For the 30 R9 sample items, the recorded current-label comparison found no physical conflict. If the source version post-dates the citing label, do **not** infer that the site was historically listed at the citing date; assess the frozen rule's current-label semantics and preserve the temporal caveat.
5. Only enter a human verdict after you personally inspect the primary-source evidence. Use `human_note` for multi-site / later-source-version / other caveats. If a source or version is unavailable or ambiguous, record that honestly rather than guessing.

For each `V-*` item, inspect **both** the citing label and the **relevant historical source version** listed in the worksheet, then inspect the current source version. Verify the historical physical match, product-scoped MANUFACTURE statement, and continuing site. A site named only in the current source version does not establish historical continuity.

The links below open the official DailyMed label page; the version ZIP link targets the exact archived version. If the ZIP opens instead of rendering, download it and inspect the XML. Do not use a newer version as a substitute for the recorded historical version.
