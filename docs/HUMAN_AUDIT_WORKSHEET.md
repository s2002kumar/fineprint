This worksheet lets a person check a seeded random sample using only public sources (DailyMed, FDA), without running fineprint. Record each verdict in [`human_audit_verdicts.csv`](human_audit_verdicts.csv): `VERIFIED`, `FAILED` (say what differs) or `CANNOT_TELL` (say why). Expect about 2–3 hours.

- Sample seed: `fineprint-human-audit-2026-10-20` (regenerate with `python -I scripts/make_human_audit_worksheet.py`).
- Current graph: DailyMed release 2026-10-16, FDA registration files as of 2026-10-19. Labels change: if DailyMed now shows a newer version, check the exact version through the FDA XML link, which is fixed by document ID.
- Historical replay: only label versions published on or before 2023-07-18.
- Opening the XML: any browser shows it; search the page for the DUNS. The XML location is an XPath; `assignedEntity[2]` means the second establishment block, and so on.
- To check a SHA-256 (optional): `certutil -hashfile file.xml SHA256` on Windows, `shasum -a 256 file.xml` on macOS, `sha256sum file.xml` on Linux.
